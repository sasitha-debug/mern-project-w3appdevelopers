# MERN Project - W3AppDevelopers

## Overview

This is a full-stack web application developed using the MERN stack technologies. The project includes a modern user interface, backend API integration, MongoDB database connectivity, and responsive design.

## Live Demo

https://mern-project-w3appdevelopers.vercel.app

## Features

- Responsive website design
- Dark mode support
- MongoDB database integration
- Backend API development
- Modern UI components
- TypeScript support
- Full-stack MERN architecture

## Technologies Used

### Frontend
- Next.js
- React.js
- TypeScript
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

- Git

## Installation

Clone the repository:

```bash
git clone https://github.com/sasitha-debug/mern-project-w3appdevelopers.git
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```
